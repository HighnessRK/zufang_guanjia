# V1.2.8

User explicitly authorized release V1.2.8. Remove every per-option radial
contrast mask and the clear pane's external shadow. Clip all pane contents,
including held selection feedback, to the same static capsule outline.
Concentrate refraction at the rim so background letters do not grow under
the labels. Use continuous pane reflection instead of black foreground masks.
Bind the shader's theme uniform through an inherited Theme dependency so
Android system night-mode changes update existing shader instances immediately.
Add pixel checks for corners and inactive controls; inspect light/dark scenes
with a gradient action button behind the navigation. App release only.
