# V1.2.7 glass

User explicitly requested release V1.2.7. Match Flutter clipping, highlight and
SDF geometry using one rounded rectangle. Keep optical geometry static, use
plain widgets for selection feedback. Clear mode uses one analytic capsule
lens, zero blur/tint, monotonic body magnification and curved ends. Foreground
contrast halos protect control labels. Only outside shadow is painted so it
cannot turn the light-mode lens gray. Frosted mode retains the cached general
renderer, with stable edge sampling and bounded highlights. Theme matrix and
Impeller device checks are recorded in the app validation document.
No pub.dev publication is requested.
