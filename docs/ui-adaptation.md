# 字体自适应视觉验收（进行中）

## 当前验收范围（按用户最新要求）

仅以系统字体 **100%、110%、125%** 三档作为设计与发布验收目标。
不人为放大应用字体，不以 150%／200% 的纵向大卡片作为主视觉。
三档均检查默认布局比例、间距、长姓名、完整金额／读数和操作按钮。
下方 2 倍截图记录仅为历史诊断，不代表当前要求，不能替代三档重新验收。
测试机恢复为 100%，不再恢复到先前的 125%。

原则：保留系统字体缩放，不用缩小文字、截断关键金额来隐藏布局问题。
默认字体维持紧凑布局；文字放大或屏幕变窄时改变组件排列。

## 本轮已重排

- 房间列表：三档统一移除重复房号徽标；租户、租金、状态、资产分层。
- 首页：实收和应收按宽度换行，提醒去掉右侧重复类型标签。
- 抄表：三档统一房号／费用摘要在上，水电读数等宽并排在下；超大字体仍保留整行分层分支。
- 收款：大字体房间、金额和确认按钮分层，不互相挤压。
- 收款明细默认与中等字体也统一分层，避免大金额按钮把长姓名挤成窄列。
- 收据：合计金额独立成行；编号、姓名、日期和金额大写按实际文字宽度换层，
  不缩小无障碍字体；预览操作区大字体纵向排列。
- 租金报表：快捷区间自动换行，大字体起止日期上下排列，移除日期缩字。
- 详情：短标签和值在可容纳时同行，长说明上下排列，不一律拉成长卡。
- 编辑：大字体标签在输入框上方；楼层、房型及字段说明对齐。
- 统计：大字体月报及欠费项目纵向组织金额与状态。
