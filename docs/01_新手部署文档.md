## 1. 准备电脑环境

### 1.1 安装 Flutter（Windows / macOS 通用）

1. 打开 <https://docs.flutter.dev/get-started/install>，下载 **Flutter 稳定版** 压缩包；
2. 解压到一个 **不要有中文和空格** 的目录，例如 `D:\flutter` 或 `~/flutter`；
3. 把 `flutter/bin` 加入系统环境变量 `PATH`；
4. 打开终端执行：

```bash
flutter --version     # 能打印版本号即成功
flutter doctor        # 检查环境，按提示补齐缺失项
```

> ⚠️ 本项目要求 **Flutter 3.24 及以上稳定版**。

### 1.2 安装 Android 开发环境

有两种方式，**推荐方式 A**：

**方式 A（最简单）：安装 Android Studio**
1. 下载安装 Android Studio：<https://developer.android.com/studio>
2. 首次启动 → `More Actions` → `SDK Manager`：
   - SDK Platforms：勾选 **Android 14 (API 34)**
   - SDK Tools：勾选 **Android SDK Build-Tools 34**、**Android SDK Command-line Tools**、**Android SDK Platform-Tools**
3. 执行 `flutter doctor`，提示 Android licenses 时输入：

```bash
flutter doctor --android-licenses
```

**方式 B（命令行）**：参照 `docs/02` 中「Android SDK 命令行安装」一节。

### 1.3 手机开启开发者模式（真机调试用）

1. 设置 → 我的设备 → 全部参数 → 连续点击 **MIUI 版本 / OS 版本** 7 次
2. 设置 → 更多设置 → 开发者选项 → 打开 **USB 调试**
3. 用数据线连接电脑，手机弹窗点「允许调试」

## 2. 获取项目源码

```bash
# 方式一：直接解压本项目压缩包
# 方式二：从 CODING 仓库克隆
git clone https://你的团队.coding.net/p/你的项目/git/仓库名.git
cd 仓库名
```

项目根目录应当能看到 `pubspec.yaml`、`lib/`、`android/`、`.coding-ci.yml`。

---

## 3. 安装依赖并本地运行

```bash
# 1. 拉取依赖
flutter pub get

# 2. 真机运行（手机连着电脑）
flutter run

# 3. 模拟器运行（先在 Android Studio 里创建一个 AVD）
flutter run -d emulator-5554
```

首次运行会自动下载 Gradle，耗时 5～15 分钟，属正常现象。

**验证 APP 是否正常：**
- 启动后应看到「首页」四个数据卡片；
- 底部是 **液态玻璃磨砂导航栏**，共 4 个 Tab：首页 / 房间 / 抄表 / 设置；
- 进「设置中心 → 关于」能看到版本号与运行环境。

## 4. 本地打包 APK

### 4.1 生成 Gradle Wrapper（首次需要）

```bash
# Windows / macOS / Linux 都执行这条
bash android/ensure_gradle_wrapper.sh
```

> 说明：Gradle Wrapper 的 `gradle-wrapper.jar` 是二进制文件，仓库里只保留了
> 配置文件，这条命令会自动补齐它（联网下载一次即可）。

### 4.2 打包

```bash
flutter build apk --release
```

产物位置：

```
build/app/outputs/flutter-apk/app-release.apk
```

把这个 APK 发到手机安装即可。**未配置签名时使用 debug 签名，可正常安装使用。**

### 4.3 只想要更小的包（可选）

```bash
flutter build apk --release --split-per-abi
# 生成 app-arm64-v8a-release.apk 等，体积约小 40%
# 常见手机选 arm64-v8a 即可
```

## 5. 上传到 CODING 并自动构建

### 5.1 创建 CODING 项目与仓库

1. 登录 <https://coding.net> → 创建团队 → 创建项目；
2. 项目内 **代码仓库** → 新建 Git 仓库（名称随意，如 `zufang-guanjia`）。

### 5.2 推送代码

```bash
git init
git add .
git commit -m "init: 租房管家 v1.0.0"
git remote add origin https://你的团队.coding.net/p/你的项目/git/仓库名.git
git push -u origin master
```

### 5.3 触发构建

推送完成后，CODING 的 **云原生构建（CNB）** 会自动读取根目录的 `.coding-ci.yml`
并在 `master` 分支 push 时触发构建。

查看构建：

> 项目 → 左侧菜单「持续集成 / 云原生构建」→ 构建记录 → 点进最新一次 → 查看各阶段日志

### 5.4 构建流程说明

| 阶段 | 做什么 |
|---|---|
| 安装构建环境 | 装 JDK17 + Android SDK + Flutter（有缓存，二次构建秒过） |
| 还原签名文件 | 把 Base64 的 keystore 还原成 `android/key.jks` |
| 编译正式版 APK | `flutter build apk --release` |
| 归档 APK 制品 | 上传到 CODING 制品库，网页直接下载 |
| 完成 | 输出成功提示 |

### 5.5 下载 APK

**方式一（推荐）**：项目 → **制品管理** → 制品仓库 → 找到 `zufang_guanjia_x.x.x.apk` → 下载

**方式二**：构建详情页 → 最后一个阶段日志 → 产物列表

## 6. 配置正式签名

⚠️ **不配置也能出包**（debug 签名），但无法上架应用市场，且换电脑安装会冲突。

完整步骤见 **docs/02_Keystore生成与CODING配置.md**，摘要：

```bash
# 1. 本地生成 keystore
keytool -genkey -v -keystore key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload

# 2. 转 Base64
base64 -w 0 key.jks > key.jks.b64        # Linux
# certutil -encode key.jks key.b64        # Windows

# 3. 在 CODING「项目设置 → 研发资源 → 环境变量」添加：
#    KEYSTORE_BASE64 / KEYSTORE_PASSWORD / KEY_PASSWORD / KEY_ALIAS
```

## 7. 常见问题

### Q1：`flutter pub get` 报错找不到某个包
执行 `flutter clean && flutter pub get`；仍失败请确认 Flutter 版本 ≥ 3.24。

### Q2：构建卡在 `Downloading Gradle...`
正常，首次 5～15 分钟。二次构建会走缓存。若网络受限，可执行
`bash android/ensure_gradle_wrapper.sh` 预生成 wrapper。

### Q3：Android 13+ 手机收不到通知
首次启动 APP 会弹出通知权限请求，请点「允许」。
也可以在手机 **设置 → 应用管理 → 租房管家 → 通知** 里手动打开。

### Q4：澎湃OS 焦点通知没有生效
焦点通知的「模板化展示」需要在小米开放平台提交模板（个人开发者也可申请）。
未申请时 APP 会自动降级为「高优先级常驻通知」，功能不受影响。
详见 `docs/03` 的「通知适配说明」。

### Q5：`build/` 目录下找不到 APK
先执行 `bash android/ensure_gradle_wrapper.sh`，再 `flutter build apk --release`。
若报 Gradle 相关错误，把完整报错发出来即可定位。

### Q6：如何恢复备份数据
APP → 设置中心 → 数据管理 → 数据恢复 → 选择之前备份的 zip 文件。
